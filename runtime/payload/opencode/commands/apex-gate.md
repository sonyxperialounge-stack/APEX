description: Run the APEX completion gate
---

Call `apex_gate`.

If it passes, write the completion report: counts by status, what was built, what was proven and
by which command, what was NOT proven and why, blocked items with their unblocking action, and
genuine remaining limitations.

If it fails, list every unmet check and state plainly that the work is not complete. A precise
"19 of 23 verified" is worth more than a confident "done".
