## Notes / surprises
- `assert.throws(fn, regex)` matches the error MESSAGE, not the ApexError code: `homeSubdir` throws "Unsafe home subdirectory …", `assertContained` throws "Path escape refused: …". The regexes assert the message text (the code string PATH_ESCAPE appears only in the `code` field).
- `openTrustStore.grant` takes `{skillId, contentHash, tier, grantedBy}` (no version/grantedEffects — that is the extension grant shape, not the skill one); `hashSkillContent(file)` is async and hashes the file's bytes.
- Fixture injection coverage and the scanner's deny rules were already aligned from earlier packets; the suite needed no implementation changes — it is a consolidation pass, as designed.
