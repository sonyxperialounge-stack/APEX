## Harness notes (portability, learned by running it)
- GNU tar reads `C:/…` as a remote host and msys tar misreads backslashes — the suite runs tar with a bare filename and `cwd` set to the tarball's directory, the only spelling every tar accepts.
- On Windows, `spawn("npx", …)` needs `shell: true` (npx is a `.cmd`); `rmSync` of the child's cwd can EPERM while the process dies — cleanup is tolerant, the handshake result stands.
