## Surprises

- The payload ships its own README copy and `sync-payload.mjs` rewrites repo-only links on
  copy — a new repo doc link silently breaks `payload.test.ts` until a rewrite exists. The
  failure arrived one full verify after the docs looked green.
- `sub === "x"` if-chain dispatch (session/home CLI) vs `case "x":` switch (memory/skills/
  archive): the doc test's surface parser had to learn both, or two groups looked empty.
- `runtime/README.md` line 1 is the `# apex-agent` heading; a `\s+`-based command regex
  captured "The" (case-insensitive) across the blank line as a "command". Command parsing
  now requires single-space separators — aligned comment columns and wrapped lines are
  prose, not invocations.
