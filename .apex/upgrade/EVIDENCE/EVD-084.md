## Correctness notes from the first run
- PERF-T06: prune's `isOld` requires the session CLOSED/ABORTED **and** the oldest event
  timestamp older than the cutoff — the fixture ages its event 3 days and closes the session
  before pruning. Retention cannot lower precedence because the policy only ever sees aged,
  closed material; the assertion also re-checks pinned/safety content survives.
- PERF-T07: records must enter through the real factory (`resolveCandidate`) — a hand-built
  literal fails the MemoryRecordV1 contract at commit, which is the store defending itself.
- PERF-T02: the frontmatter `name` obeys `^[a-z0-9][a-z0-9-]{1,63}$`; bodies still resolve by
  directory id on explicit read.
