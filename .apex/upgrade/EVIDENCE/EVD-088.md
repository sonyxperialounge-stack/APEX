## 2. Bugs found and fixed during the packet

1. **Generator dropped the last block of every parsed section** — the lookahead
   regex `(?=^### |\Z)` treats `\Z` as a literal "Z" in JavaScript (not
   end-of-input), so the final ledger row (REQ-112/REQ-UX-004), the final register
   row (REQ-L2-001) and the final V-record were silently missed. Rewrote
   `parseLedger`/`parseVerifications` to split-based parsing (the same approach
   `ledger.ts` itself uses).
2. **Register-id regex could not match `REQ-L2-001`** — `REQ-[A-Z]+-\d+` stops at
   the digit inside the family code "L2". Fixed to `REQ-[A-Z0-9]+-\d+` in all four
   regex sites (generator ×4, reconcile ×1); register id inventory went 115 → 116
   and every row now maps.
3. **Pack hygiene (caught by the suite, not by me)** — `package.json` `files`
   shipped all of `scripts/`, so the packed artifact contained the upgrade-process
   tools (PKG-T03 failed on `package/scripts/traceability.mjs` naming
   `army-update-plan`). Narrowed to `scripts/sync-payload.mjs` — the only script
   PKG-T01 requires. The release package now ships no upgrade scaffolding.
